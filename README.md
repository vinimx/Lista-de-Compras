## 📝 Descrição

Este projeto foi desenvolvido para fins de estudo, implementando uma aplicação web de lista de compras interativa. O projeto utiliza HTML5, CSS3 e JavaScript puro, seguindo boas práticas de programação e arquitetura modular.

## 🚀 Funcionalidades

- Adicionar itens à lista de compras
- Marcar itens como concluídos
- Remover itens da lista
- Armazenamento local (localStorage) para persistência dos dados
- Interface responsiva e amigável
- Formatação de data e hora em português brasileiro
- Animações suaves e feedback visual
- Design moderno com ícones do Font Awesome

## 🛠️ Tecnologias Utilizadas

- HTML5 - Estruturação do conteúdo
- CSS3 - Estilização e animações
- JavaScript (ES6+) - Lógica e interatividade
- LocalStorage - Armazenamento de dados
- Font Awesome - Ícones
- Arquitetura Modular - Organização do código em módulos

## 📚 Aprendizados

- Programação Orientada a Objetos
- Módulos ES6
- Armazenamento Local
